# DreamHome - Real Estate Website

A responsive real estate website built using HTML5 and CSS3.

## Project files
- `index.html` — Home page with property listings, search UI, about, services, testimonials and footer.
- `property.html` — Property details page with image gallery, overview, address, features and inquiry form.
- `style.css` — Shared responsive styling for desktop, tablet and mobile.

## Run locally
1. Download and extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Publish using GitHub Pages
1. Create a GitHub repository and upload all project files.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then click **Save**.

## Notes
- Property information is sample content. Replace it with accurate information before publishing.
- Images are loaded from Unsplash and require an internet connection.
- The search form is a front-end demonstration, not connected to a database.
- The inquiry form opens the visitor's email application; automatic enquiry handling needs a backend.
